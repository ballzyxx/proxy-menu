**The number of menu items depends on the installed modules.**

If Merchant in the menu does nothing, talk to a city merchant and click **Shop** once so the menu can learn that NPC. After a server restart, visit merchants in Highwatch (Vanguard / forge), Velika (Freedom Plaza), and Castanica. Standing next to them is not enough — you need to open Shop.

Bank, guild bank, and wardrobe do not need a nearby NPC.

## Commands

| Toolbox (`/8`) | Hotkey | Description |
| --- | --- | --- |
| **m** | Ctrl+Shift+M | Open the menu |
| **m $dang** | Ctrl+Alt+H | Vanguard teleport to dungeons |
| **m $setting** | Ctrl+Alt+S | Extra settings |
